# 诗文笺使用说明

## 课文阅读

首页目录按册次展示 71 篇课文与各篇注释数量。阅读页中带点线的词句具有随文注释，电脑端在右侧面板展示，手机端在底部面板展示。

注释面板包含原句、完整注释与出处。“本篇全部注释”提供该篇全部记录，包括未能精确关联到原文的注释。阅读字号支持两档切换。

从查询结果进入课文时，页面尝试定位到对应原句；无法精确匹配时显示定位提示。返回上一页可恢复此前的查询条件与页面位置，“课文目录”返回未筛选的目录。

## 查询与筛选

查询范围包括全部内容、词条与关键词、原句、释义。册次与篇目筛选可进一步缩小范围。篇名查询同时展示相关课文入口。

结果按以下次序分组：

1. 精确词条。
2. 原注释中提取的独立关键词。
3. 包含查询内容的相关词条。
4. 原句匹配。
5. 释义匹配。

标有“注释关键词”的结果来自完整注释中的明确分项解释，不是额外增加的教材注释。结果卡片展开后同时保留完整注释，便于结合上下文理解。

“同词例句”展示其他课文中的相同词条或独立关键词，不将所有包含相同字词的句子视作同词记录。

## 收藏与自测

注释卡片支持收藏与取消收藏，“我的收藏”集中展示已收藏的注释，并支持册次和篇目筛选。

“隐藏释义自测”隐藏结果预览和卡片内的释义，展开卡片后可通过“显示释义”核对答案。该功能用于自主复习，不记录答题分数或掌握程度。

首页展示最近查询记录，支持再次查询与清空。阅读位置和自测设置由当前浏览器保存。

## 本地记录与离线使用

学习记录仅保存于当前浏览器，不上传至账号服务。不同设备、浏览器、网站域名与离线文件之间不自动同步，清理浏览器数据可能导致记录丢失。当前版本没有记录导入导出功能。

在线版的页面与程序使用多个文件，通过网站访问。离线单文件包含完整课文、注释、样式与程序，打开后使用查询和阅读功能无需联网；页脚中的外部参考链接仍需要网络。

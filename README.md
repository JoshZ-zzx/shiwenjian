# 诗文笺

**高中古诗文注释与伴读。**

诗文笺是一款面向高中语文学习的古诗文阅读与注释查询工具，收录必修上、下册及选择性必修上、中、下册的 **71 篇课文、2349 条原始注释**，支持随文查词、跨篇检索、收藏与复习自测。

**[在线使用](https://joshz-zzx.github.io/shiwenjian/)** · [使用说明](docs/usage.md) · [问题反馈](https://github.com/JoshZ-zzx/shiwenjian/issues)

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 课文伴读 | 按册次浏览篇目，点击原文中带点线的词句查看注释 |
| 注释查询 | 搜索词条、原句、释义或篇名，支持按册次、篇目和查询范围筛选 |
| 关键词检索 | 从完整注释的明确分项解释中提取关键词，支持查询整句注释中的单个词义 |
| 同词例句 | 比较其他篇目中相同词条或独立关键词的原句与注释 |
| 我的收藏 | 收藏注释，集中查看与复习 |
| 释义自测 | 隐藏释义，按需显示答案 |
| 阅读记录 | 保存最近查询、自测设置与阅读位置 |
| 阅读适配 | 支持字号切换，电脑侧栏与手机底部注释面板 |

## 使用方式

目录提供按册次排列的课文入口，搜索框支持词语、原句、释义和篇目名称，例如“信”“确实”“兰亭集序”。查询结果按精确词条、独立关键词、相关词条、原句匹配和释义匹配分组。

注释卡片包含原句、完整注释与出处，并提供课文定位、收藏和同词例句功能。课文阅读页保留整篇全部注释，无法精确关联原文的记录仍可在其中查看。

在线版通过浏览器使用，无需安装应用。项目支持生成包含课文、注释、样式与程序的离线单文件，生成后的 HTML 可直接在浏览器中打开。

## 数据保存

收藏、最近查询、自测设置与阅读位置保存在当前浏览器本地，不会自动跨设备、跨浏览器或跨域名同步。清理浏览器数据可能删除这些记录。当前版本不支持学习记录导入导出与账号同步。

[ToolBox 旧版](https://joshzhangzzx.top/ClassicalChinese.html)仍可访问，其本地记录与独立站点不共享。

## 内容范围

内容沿用原文件标注的部编版高中语文必修与选择性必修数据，涵盖词义、虚词、人名地名、典故与句意，不自动判定词性。注释关键词是原始注释的检索辅助，不计作新增教材注释。

教材出版年份、版次与印次尚未确认，内容未逐条对照纸质教材。存在歧义时需结合完整注释与原文阅读；详细校对说明见页面页脚。数据完整性检查不等同于教材内容的学术校订。

## 项目与许可

项目采用原生 JavaScript，页面、样式、教材数据与检索逻辑分别维护，无第三方运行依赖。

项目源自 [ToolBox 的 ClassicalChinese.html](https://github.com/JoshZ-zzx/ToolBox/blob/main/ClassicalChinese.html)，来源版本与数据校验信息记录于 [data/provenance.json](data/provenance.json)。项目采用 [GPL-3.0 许可证](LICENSE)，页面保留原有版权标识。
